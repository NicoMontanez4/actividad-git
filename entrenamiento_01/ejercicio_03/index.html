Risotto de hongos y parmesano

Indice

Para preparar un risotto de hongos y parmesano, primero se deben limpiar y cortar los hongos en láminas. En una sartén grande se calienta un poco de aceite de oliva y se cocina una cebolla finamente picada hasta que quede transparente. Luego se agregan los hongos y se cocinan durante unos minutos. A continuación, se incorpora el arroz arborio y se mezcla durante un par de minutos para que absorba los sabores. Después se agrega un poco de vino blanco y se cocina hasta que el alcohol se evapore. A partir de ese momento, se incorpora caldo de verduras caliente de a poco, agregando más cada vez que el arroz absorba el líquido. Es importante revolver constantemente para conseguir una textura cremosa. Cuando el arroz está cocido pero todavía conserva una ligera firmeza en el centro, se retira del fuego y se agrega manteca y queso parmesano rallado. Se mezcla bien y se deja reposar unos minutos antes de servir.

Lasagna de carne y salsa bechamel

Indice

Para preparar una lasagna de carne, primero se debe elaborar el relleno. En una sartén grande se calienta aceite y se cocina cebolla, ajo y zanahoria picados. Luego se agrega carne picada y se cocina hasta que esté completamente dorada. Se incorpora tomate triturado, sal, pimienta, orégano y otras especias a gusto. La preparación se cocina a fuego bajo durante aproximadamente 30 minutos para concentrar los sabores. Mientras se prepara la carne, se puede elaborar una salsa bechamel calentando manteca y agregando harina. Se mezcla hasta formar una pasta y luego se incorpora leche poco a poco, revolviendo constantemente para evitar que se formen grumos. Se cocina hasta obtener una salsa espesa y cremosa. Para armar la lasagna, se coloca una capa de salsa de carne en una fuente para horno, seguida de las láminas de pasta, salsa bechamel y queso. Se repiten las capas hasta completar la fuente y se termina con abundante bechamel y queso rallado. Finalmente, se lleva al horno hasta que la pasta esté cocida y la superficie quede dorada.

Lomo de cerdo relleno con verduras

Indice

Para preparar un lomo de cerdo relleno, primero se abre la pieza de carne realizando un corte longitudinal para poder extenderla. Se condimenta con sal, pimienta, ajo y hierbas aromáticas. Luego se prepara el relleno utilizando espinaca salteada, cebolla, morrón y queso. Se distribuye el relleno sobre la carne y se enrolla cuidadosamente hasta formar nuevamente el lomo. Una vez enrollado, se ata con hilo de cocina para mantener su forma durante la cocción. Se sella la carne en una sartén caliente con un poco de aceite, procurando dorar todos sus lados. Después se coloca en una fuente para horno y se cocina hasta que esté completamente cocida. Mientras tanto, se pueden preparar papas y zanahorias asadas como acompañamiento. Se cortan en trozos, se condimentan con aceite, sal, pimienta y romero y se llevan al horno junto con la carne. Cuando el lomo está listo, se deja reposar unos minutos antes de cortarlo en rodajas y servirlo acompañado de las verduras.

Cheesecake de frutos rojos

Indice

Para preparar un cheesecake de frutos rojos, primero se realiza la base triturando galletitas y mezclándolas con manteca derretida. La preparación se coloca en el fondo de un molde desmontable y se presiona hasta formar una capa compacta. Luego se lleva al refrigerador mientras se prepara el relleno. Para el relleno, se bate queso crema con azúcar hasta obtener una mezcla suave. Se agregan huevos de a uno, incorporando cada uno antes de agregar el siguiente. Luego se incorpora crema de leche, esencia de vainilla y un poco de ralladura de limón. La mezcla se vierte sobre la base de galletitas y se cocina en un horno a temperatura moderada hasta que el centro quede firme pero ligeramente cremoso. Una vez cocido, se deja enfriar completamente y se lleva al refrigerador durante varias horas. Para terminar, se prepara una salsa de frutos rojos cocinando frutillas, arándanos y frambuesas con azúcar. Cuando la salsa se enfría, se coloca sobre el cheesecake antes de servirlo.
